# دليل الاستخدام والتطوير

## الاستخدام السريع

1. سجّل الدخول بحساب مدير المدرسة.
2. من صفحة **الفصول والمواد** أضف أو عدّل:
   - المراحل
   - الصفوف
   - الشُعب
   - المواد
   - القاعات
3. من صفحة **المعلمون** اربط كل معلم بالمواد والشُعب المناسبة.
4. من صفحة **الجدول**:
   - اختر الشعبة.
   - افتح تبويب **أوقات الحصص** لتعديل أوقات الحصص التسع.
   - ارجع إلى تبويب **الجدول** واضغط على خانة فارغة لإضافة حصة.
   - استخدم السحب والإفلات لنقل الحصة بين الأيام أو الفترات.

## سير إعداد مدرسة جديدة

1. إنشاء المدرسة أو الدخول كمدير مدرسة.
2. إضافة الصفوف والشُعب.
3. إضافة المواد والقاعات.
4. إضافة المعلمين وربطهم بالمواد والشُعب.
5. ضبط أوقات الحصص.
6. بناء الجدول الأسبوعي.
7. متابعة الطلاب، الحضور، الرسائل، والتقارير.

## التطوير

### Backend

- الملف الرئيسي: `/app/backend/server.py`
- المسارات الإضافية: `/app/backend/routes_extended.py`
- قاعدة البيانات: MongoDB من `MONGO_URL` و `DB_NAME`
- يجب استبعاد `_id` من أي response قادم من MongoDB.

### Frontend

- الملف الرئيسي: `/app/frontend/src/App.js`
- الصفحات: `/app/frontend/src/pages/`
- مكوّنات Shadcn: `/app/frontend/src/components/ui/`
- API base URL من `REACT_APP_BACKEND_URL` فقط.

## فحوصات قبل التسليم

- `GET /api/health` يرجع healthy.
- تسجيل الدخول يعمل.
- إضافة مادة تعمل بدون 500.
- حفظ أوقات الحصص يعمل.
- إضافة حصة في الجدول تعمل بدون 500.
- صفحة الجدول تظهر تبويب **أوقات الحصص**.
