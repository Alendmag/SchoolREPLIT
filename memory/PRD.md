## APIs الجديدة

| Endpoint | الوصف |
|----------|-------|
| `/api/onboarding/complete` | إكمال إعداد المدرسة |
| `/api/notifications/` | قائمة الإشعارات |
| `/api/notifications/{id}/read` | تحديد كمقروء |
| `/api/notifications/read-all` | تحديد الكل كمقروء |
| `/api/notifications/unread-count` | عدد غير المقروءة |
| `/api/reports/{type}/preview` | معاينة التقرير |
| `/api/reports/{type}/export` | تصدير PDF/Excel |
